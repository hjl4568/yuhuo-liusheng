核心设计 · DESIGN

六个核心设计

不是功能清单，而是我们对"把话说出去、把物交还回去"这件事的全部坚持。

①
表达与交还，不是信托
不托管财产，只托管一段表达。我们的全部价值，是"把话说出去、把物交还回去"。
②
主动送达，像快递公司
是我们把内容发给对方，而不是对方来领。从根源规避冒领、诈骗与伦理风险——重点永远是"交还"，不是"宣发"。
③
死亡触发 + 替补执行链
以"客户离世"作为终极发令枪；亲友、医生、法医发现后可作替补执行，发送前多方验证，绝不凭"被打开"就发。
④
纸与物的记忆价值
纸有线性、平面、弯曲、折叠的回忆；一件轻物，承载说不清的重量。这也是未来"实物交付"的情感内核与收费依据。
⑤
长期陪伴：每 5 年更新
推荐并提醒定期更新内容；临近到期，提醒频率逐年递增，避免遗忘，也避免家庭矛盾。
⑥
匿名公开与改编
经你授权，内容可匿名用于公益陈列；也鼓励改编成动漫、小说、电影，收益分配写进合同。
产品愿景 · ROADMAP

产品愿景时间线

我们不想一次做满，而想沿着"轻量化、走叙事"的路线，一步步把"用现在设定未来"做实。下面是从此刻到远期的五段路。

阶段一 · 此刻（MVP 试水）

电子内容免费，用现在设定未来

文字、录音、影像——你设定未来的时刻和收件人，到了那一刻，我们替你主动送达到对的人手里。 我们主张用简单普通的媒介留存心意，不铺张。此阶段以自愿赞赏验证付费意愿——出于自愿，不承诺对价。
邮件/短信主动送达 轻量化内容服务 自愿赞赏试水
阶段二 · 媒介回归（实物交付）

纸与物的记忆价值，是收费的依据

纸有线性、平面、弯曲、折叠的回忆；一件轻物，承载说不清的重量。纸与物的回归，是"实物交付"的情感内核，也是合理的收费依据。 实物交付走具备资质的民营合作方或 EMS，规避邮政专营；我们不碰重资产，只做轻量寄递。
手写信件 随身物件寄递 不涉邮政专营
阶段三 · 长期陪伴（周期运营）

每 5 年更新，提醒越来越密

默认每 5 年一个周期提醒你更新；临近到期，频率逐年递增，直到每月、每周——你不会"失忆"到处理不了，也避免家庭矛盾。 同时建立安全池 / 敏感池严格隔离，配套规范的用户手册。
5年更新周期 到期递增提醒 内容池隔离
阶段四 · 价值放大（公开与改编）

匿名公开 + 改编，让故事不止昙花一现

经你授权，内容可匿名用于公益陈列——你个人并不渺小，这些故事值得被更多人看见。 我们也鼓励改编成动漫、小说、电影；收益分配（给对象 / 捐公益 / 留平台）写进合同。
匿名公益陈列 改编授权 收益分成进合同
阶段五 · 社会网络（远期）

志愿者、展馆与跨界共生

建立志愿者公益配送网络（认证证书 + 适度补贴）；办脱口秀式倾诉舞台；与养老院 / 临终关怀机构做 B 端合作； 并和法律、编导、出版、媒体跨界协作，办展览、办书展、做公共演讲。
志愿者网络 公益展馆 临终关怀 B 端 跨界合作
合规 · 电子签名 · COMPLIANCE

合规与电子签名（搭配 e签宝）

e签宝：未接入（规划中）

我们做的只是保管与交还，不是创造、也不是宣发，法律风险本身很低。但我们要把过程做规范——下面这些合规设计，正是为对接 e签宝 这类合规第三方电子签名 / 存证服务而准备。

内容审核人工 + AI 双重审核，加密防盗、抵御攻击
多处确认勾选合同内嵌确认/同意/拒绝环节，落实责任
双保险与知情权保留双方知情权与接受/拒绝权
公益提取比例用户手册载明按额度提取一定比例用于公益
安全池 / 敏感池严格界限隔离，防污染、建漏洞库
用户手册规范详尽手册，规避误操作与同行风险
现在（MVP）
平台自建手写电子签名 + 内容 SHA-256 哈希存证，作为轻量法律背书，已在合同页可用。
→
规模化后（待接入）
接入 e签宝 等合规电子签名服务，获更强法律效力与出证能力。合同文本已就上述合规点全部固化，可直接迁移对接。

接入 e签宝 的前提：需企业 / 个体工商户主体 + 注册 e签宝开发者 + API 对接 + 付费。 详细方案见 合规与 e签宝方案文档。
