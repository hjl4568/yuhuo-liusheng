## 关于 · ABOUT

我们想做一个地方，让人在此刻留下想说的话、想留的物——文字、录音、影像，甚至一封手写的信、一件随身的小物件。
你设定一个未来的时刻和收件人，到了那一刻，我们替你把这份心意，安静地交还到对的人手里。

**三个关键词**

- 你留下话语：文字、录音、影像，甚至一封手写的信、一件随身的小物件
- 你设定未来：指定一个未来的时刻与收件人，时间到了才送达
- 我们主动交还：替你把心意送达对的人手里，不是对方来领

> 我们做的不是信托，也不是银行，而是 **表达与交还**——只走叙事，不碰财产。

**创始人的原话**

> "我不是在做宣发，是把它交还给目标对象，这里的重点是交还，是传递。"

> "当我在意的人不再出现于我的世界——我们称之为「存在性的退场」，触发这个条件，我就可以去执行我的动作——向指定的目标对象发送一段讯息。"

## 核心设计 · DESIGN

不是功能清单，而是我们对"把话说出去、把物交还回去"这件事的全部坚持。

1. **表达与交还，不是信托**  
   不托管财产，只托管一段表达。我们的全部价值，是"把话说出去、把物交还回去"。

2. **主动送达，像快递公司**  
   是我们把内容发给对方，而不是对方来领。从根源规避冒领、诈骗与伦理风险——重点永远是"交还"，不是"宣发"。

3. **存在性触发 + 替补执行链**  
   以「一个人不再出现在你的世界里」作为终极发令枪——我们称之为存在性的退场；亲友、医生、法医察觉后可作替补执行，发送前多方验证，绝不凭「被打开」就发。

4. **纸与物的记忆价值**  
   纸有线性、平面、弯曲、折叠的回忆；一件轻物，承载说不清的重量。这也是未来"实物交付"的情感内核与收费依据。

5. **定期陪伴：常更常新**  
   推荐并提醒你定期更新内容；临近到期，提醒频率逐年递增，避免遗忘，也避免家庭矛盾。

6. **匿名公开与改编**  
   经你授权，内容可匿名用于公益陈列；也鼓励改编成动漫、小说、电影，收益分配写进合同。

## 理想场景 · SCENES

7 帧手绘分镜，展示一封写给未来的信如何被送达。不是营销，只是工作方式的一种展示。

1. **开场** · 全景·固定·微俯：傍晚客厅，林叔坐在沙发角看手机，茶几上旧搪瓷杯。
2. **录入** · 过肩中景→特写·推镜：删了又改，只留三行字和一张旧照片。
3. **设定触发** · 特写·推近：手指选了「小满 25 岁生日」。
4. **托付** · 中景·固定·平视：信封装好，放进一排格架里，和很多封信一起安静待着。
5. **时间流过** · 蒙太奇·跳切·轻微推拉：四季翻页，格架上一格轻轻亮了一下。
6. **不经意送达** · 旁观者中远景·固定：多年后，小满回家，门把手上挂着那只无落款的信封。
7. **收讫与退出** · 特写·固定→淡出：拆开是那张旧照片，林叔在手机上点了注销。

## 产品愿景 · ROADMAP

### 阶段一 · 此刻（0–3 个月，MVP 试水）

轻量内容（文字、小体积录音）免费托管；你设定未来的时刻和收件人，到了那一刻，我们替你主动送达到对的人手里。

此阶段以**自愿赞赏**验证意愿——出于自愿，不承诺对价。

- 文字 / 小音频
- 主动送达
- 自愿赞赏试水

### 阶段二 · 半年内（轻量实物交付）

纸有线性、平面、弯曲、折叠的回忆；一件轻物，承载说不清的重量。手写信件、随身小物件走具备资质的民营合作方或 EMS 交付，规避邮政专营；我们不碰重资产，只做轻量寄递。

- 手写信件
- 随身物件寄递
- 不涉邮政专营

### 阶段三 · 一到两年（试水与合规）

临近到期递增提醒、安全池 / 敏感池隔离、用户手册规范；并对接 e签宝 等合规电子签名，让每一份交还都有据可依。

- 周期提醒
- 内容池隔离
- 合规电子签

> 更远的可能（公开陈列、跨界合作等），我们边走边看，不画大饼——先把眼前这一程走稳。

## 合规 · 电子签名 · COMPLIANCE

我们做的只是**保管与交还**，不是创造、也不是宣发，法律风险本身很低。但我们要把过程做规范。

**已做的合规设计**

- 内容审核：人工 + AI 双重审核，加密防盗、抵御攻击
- 多处确认勾选：合同内嵌确认/同意/拒绝环节，落实责任
- 双保险与知情权：保留双方知情权与接受/拒绝权
- 公益提取比例：用户手册载明按额度提取一定比例用于公益
- 安全池 / 敏感池：严格界限隔离，防污染、建漏洞库
- 用户手册规范：详尽手册，规避误操作与同行风险

**当前 → 未来**

- **现在（MVP）**：平台自建手写电子签名 + 内容 SHA-256 哈希存证，作为轻量法律背书，已在合同页可用。
- **规模化后（待接入）**：接入 e签宝 等合规电子签名服务，获更强法律效力与出证能力。

> 接入 e签宝 的前提：需企业 / 个体工商户主体 + 注册 e签宝开发者 + API 对接 + 付费。
