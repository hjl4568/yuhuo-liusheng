# 用腾讯云「轻量应用服务器」部署「长夜余火 / 余火·留声」

> 为什么选它：**年付约 60–200 元**（比 Railway 便宜 5–8 倍）、**服务器一直在线不用保活**、**SQLite 写在磁盘上长期不丢**（不像 Render/Koyeb 重启就清空）。代码零改造，用仓库里已有的 Dockerfile 原样跑。

---

## 第 0 步（重要）：把 GitHub 仓库设为 Public

部署脚本要从 GitHub 拉代码。你的仓库现在是**私有**，服务器直接 `git clone` 会报 403。两个办法：

- **办法 A（推荐，最简单）**：把仓库设为公开。
  GitHub 仓库页 → **Settings** → 最底部 **Danger Zone** → **Change visibility** → **Make public**。
  ✅ 安全：仓库里**从不含任何密码**（`.env` / `.env.prod` 已被 `.gitignore` 排除，密钥只在你服务器本地）。公开出去的只有业务代码，无风险。
- **办法 B（想保持私有）**：用 Deploy Key。
  服务器上 `ssh-keygen -t ed25519`，把 `~/.ssh/id_ed25519.pub` 内容加到 GitHub 仓库 **Settings → Deploy keys**（勾 Allow write 不用，只读即可），clone 地址改成 `git@github.com:hjl4568/yuhuo-liusheng.git`。

下面按**办法 A** 继续。

---

## 第 1 步：买轻量应用服务器

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/lighthouse) → **轻量应用服务器** → **新建**。
2. **镜像**：选 **Docker CE**（应用镜像，自带 Docker，省去装环境）；或选 **系统镜像 Ubuntu 22.04**（后面手动装 Docker 也行）。
3. **地域**：
   - 国内（上海/广州/北京）：最便宜、访问最快，但**绑自己域名需 ICP 备案**（见第 6 步）。
   - 中国香港：免备案、可立即绑域名，但贵一些、稍慢。
   - 新手建议先选**国内**，先用 IP 跑通，备案后再绑域名。
4. **套餐**：选 **2 核 2G**（MVP 足够）。新用户常有首年 50–100 元活动价，常规续费约 100–200 元/年。
5. 设置登录密码（记好），确认购买。

---

## 第 2 步：登录服务器

控制台 → 你的服务器 → **登录**（打开浏览器 WebShell，无需本地装 SSH 工具）。
进去后默认是 `root` 或 `lighthouse` 用户。下面命令若提示权限不足，开头加 `sudo`。

---

## 第 3 步：准备环境与密钥

```bash
# 1) 确保有 git（Docker 镜像若没有就装）
apt update && apt install -y git

# 2) 创建生产环境文件（含真实密码，不进 GitHub）
cd /root
nano yuhuo-liusheng/.env.prod
```

把下面内容粘进去，改成你的真实值（注意 `SMTP_PASS` 是 **163 授权码**，不是登录密码）：

```ini
NODE_ENV=production
MAIL_SERVICE=163
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_USER=changyeyuhuo2026@163.com
SMTP_PASS=你的163授权码
WORK_MAIL=changyeyuhuo2026@163.com
ADMIN_USERNAME=admin
ADMIN_PASSWORD=改成强密码
JWT_SECRET=随便一长串随机字符
APP_URL=http://你的服务器IP:3000
PORT=3000
```

> 嫌手写麻烦？也可以直接 `nano` 复制仓库里的 `.env.prod.example` 再改。
> 保存：nano 里 `Ctrl+O` 回车，`Ctrl+X` 退出。

---

## 第 4 步：一键部署

```bash
cd /root
bash <(curl -fsSL https://raw.githubusercontent.com/hjl4568/yuhuo-liusheng/master/deploy.sh)
```

脚本会：克隆代码 → 用 docker compose 构建（首次约 2–5 分钟，要编译 better-sqlite3）→ 后台启动 → 打印你的公网 IP。

> 如果 `docker compose` 报命令不存在，先装一下插件：
> `apt install -y docker-compose-plugin`，或把脚本里的 `docker compose` 改成 `docker-compose`。

---

## 第 5 步：放行防火墙 + 验证

1. 控制台 → 服务器 → **防火墙** → **添加规则**：
   应用类型「自定义」→ 协议 **TCP** → 端口 **3000** → 策略**允许** → 确定。
2. 浏览器打开 `http://你的服务器IP:3000` → 看到「长夜余火」介绍页 + 右下角「中 / EN」切换。
3. 打开 `http://你的服务器IP:3000/api/health` → 应返回 `{"status":"ok"}`。
4. 点「登记早期体验」提交一条 → 项目 163 邮箱应收到来信（前提是 `SMTP_PASS` 填对授权码）。
5. 实时数据 Tab 从占位变为真实数值。

---

## 第 6 步（可选）：绑域名 + ICP 备案

1. 在腾讯云 **DNSPod / 域名注册** 买一个域名（如 `yuhuo.example.com`）。
2. 解析：添加 **A 记录**，`@` 或 `www` → 指向服务器公网 IP。
3. **备案**：国内节点绑域名必须 ICP 备案。控制台搜「网站备案」→ 按引导提交（免费，约 1–2 周）。
   备案通过前，仍可继续用 `IP:3000` 访问。
4. 备案通过后，改 `.env.prod` 里的 `APP_URL=https://你的域名`，重启容器：
   `cd /root/yuhuo-liusheng && docker compose up -d`。

---

## 以后怎么更新（我改完代码后）

你只需登录服务器，跑一句：

```bash
bash /root/yuhuo-liusheng/deploy.sh
```

它会自动 `git pull` 最新代码并重建容器。**全程不用碰 GitHub 后台、不用学命令**，把这句记在手机里即可。

## 数据与成本说明

- **数据持久**：数据库 `yuhuo.db` 和上传文件已挂载到宿主机 `/opt/yuhuo-data`、`/opt/yuhuo-uploads`，容器重建也不丢。比 Render/Koyeb 的临时磁盘可靠得多。
- **一直在线**：轻量服务器按付费周期运行，**不休眠**，无需像 Render 那样用 cron-job 保活。
- **成本**：2 核 2G 国内首年约 50–100 元（活动价），常规续费约 100–200 元/年；香港节点免备案但约 200+ 元/年。比 Railway Hobby $5/月（≈480 元/年）便宜很多。
- **发信**：腾讯云轻量公网可连 `smtp.163.com:465`（SSL），不受 25 端口限制，国内能正常收信。
