# 长夜余火 · 后端上云部署指南

> 现状：介绍页已静态部署（可用），但注册/登录/创建胶囊/合同/后台等需要 Node 后端，目前只在你本机跑。
> 要让"进入应用"在公网也完整可用，需把后端一起部署。下面给出两条路。

---

## 方案一：腾讯云 CloudBase 云托管（推荐，容器化）

适合 Express 这类 Node 服务，不用自己管服务器。

1. **注册并实名**
   - 打开 https://cloud.tencent.com ，用微信/QQ 注册账号，完成**实名认证**（个人/企业均可）。
2. **开通 CloudBase**
   - 控制台搜索「云开发 CloudBase」→ 新建环境（选「按量计费」，新用户有免费额度）。
3. **使用云托管**
   - 进入环境 →「云托管」→「新建服务」，服务名随意（如 `yuhuo`）。
   - 代码来源选「代码仓库」并授权绑定 GitHub（把我们这个项目仓库连上），或直接「本地代码」上传。
   - 平台会自动识别 `Dockerfile`（项目已提供）。
4. **配置运行**
   - 监听端口填 `3000`。
   - **环境变量**（关键，务必填，不要上传 `.env` 文件）：
     - `MAIL_SERVICE=163`
     - `SMTP_HOST=smtp.163.com`
     - `SMTP_PORT=465`
     - `SMTP_USER=changyeyuhuo2026@163.com`
     - `SMTP_PASS=<你的163授权码>`
     - `JWT_SECRET=<随便一段长随机串>`
     - `APP_URL=<部署后给你的域名>`
     - `ADMIN_USER` / `ADMIN_PASS`（后台管理员账号密码）
   - 实例最小 0.25 核即可，按量计费很便宜。
5. **部署完成**
   - 平台会给你一个 `.app.tcloudbase.com` 域名。把前端介绍页里的 `/app.html`、各接口地址指向这个域名（或把前后端都放同一个 CloudBase 环境里）。
   - 需要自定义域名再在「网关/域名」里绑定并做 ICP 备案。

> 替代：腾讯云「轻量应用服务器」也行——建实例 → 装 Node 20 → `git clone` 拉代码 → `npm install` → `pm2 start src/index.js` → 安全组放行 3000 端口。但要比云托管多操心运维，新手更推荐云托管。

---

## 方案二：Railway / Render（更省事，非腾讯云）

如果你不坚持腾讯云，这两个平台对「连 GitHub 自动部署 Node 服务」最友好，几分钟搞定：

- **Railway**：https://railway.app → New Project → 连 GitHub 仓库 → 选本仓库 → 它会自动 `npm install && npm start`（识别 package.json）→ 在 Variables 里填上面的环境变量 → 部署完给一个 `*.up.railway.app` 域名。
- **Render**：https://render.com → New Web Service → 连仓库 → Build Command `npm install` / Start `npm start` / 端口 3000 → 填环境变量 → 给 `*.onrender.com` 域名。

免费额度足够早期验证。

---

## 环境变量对照（填平台后台，不要提交 .env）

| 变量 | 说明 | 示例 |
|---|---|---|
| `MAIL_SERVICE` | 邮件服务商 | `163` |
| `SMTP_HOST` | SMTP 主机 | `smtp.163.com` |
| `SMTP_PORT` | 端口 | `465` |
| `SMTP_USER` | 发信邮箱 | `changyeyuhuo2026@163.com` |
| `SMTP_PASS` | 授权码（非登录密码） | `UYvCa3A85YxXvSjg` |
| `JWT_SECRET` | token 签名密钥 | 任意长随机串 |
| `APP_URL` | 站点外网地址 | `https://xxx.app.tcloudbase.com` |
| `ADMIN_USER` | 后台账号 | 自定义 |
| `ADMIN_PASS` | 后台密码 | 自定义 |

> ⚠️ 真实授权码、JWT 密钥等**只填在平台的环境变量里**，切勿写进代码或提交到 git（`.env` 已在 `.gitignore` 排除）。
